## Matemática: cómo se leen los símbolos

| Símbolo | Se lee | Ejemplo hablado |
|---|---|---|
| `+` `−` `×` `÷` | plus, minus, times (multiplied by), divided by | *two plus two equals four* |
| `=` / `≠` | equals / is not equal to | |
| `>` / `<` | is greater than / is less than | |
| `≥` / `≤` | is greater than or equal to / less than or equal to | |
| `x²` / `x³` / `xⁿ` | x squared / x cubed / x to the power of n | |
| `√x` | the square root of x | |
| `%` | percent | *twenty percent* |
| `0.5` | zero point five | En inglés el decimal se escribe con **punto** |
| `1,000,000` | one million | En inglés la **coma** separa miles |
| `1/2`, `1/3`, `3/4` | a half, a third, three quarters | |
| `n!` | n factorial | |
| `( )` `[ ]` `{ }` | parentheses, square brackets, curly braces | |

> ⚠️ **Muy importante:** en inglés **3,500** = tres mil quinientos y **3.5** = tres coma cinco. Es al revés que en Colombia.
