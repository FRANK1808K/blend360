# Glosario Español–Inglés (AIF-C01)

> El examen puede realizarse en inglés aunque estudies en español: este glosario relaciona ambos términos.

| Español | Inglés | Definición breve |
|---|---|---|
| Agente | Agent | Sistema que usa un FM para razonar y ejecutar acciones multi-paso con herramientas. |
| Alucinación | Hallucination | Salida plausible pero falsa o no respaldada por los datos. |
| Aprendizaje por refuerzo | Reinforcement learning | Aprendizaje mediante recompensas al interactuar con un entorno. |
| Aprendizaje supervisado | Supervised learning | Entrenamiento con datos etiquetados. |
| Aprendizaje no supervisado | Unsupervised learning | Descubrimiento de patrones en datos sin etiquetas. |
| Ajuste fino | Fine-tuning | Re-entrenar un modelo pre-entrenado con datos etiquetados específicos. |
| Base de conocimiento | Knowledge base | Repositorio indexado (vectorial) que alimenta RAG. |
| Barreras de protección | Guardrails | Políticas que filtran entradas y salidas del modelo. |
| Cadena de pensamiento | Chain-of-thought (CoT) | Técnica de prompt que pide razonar paso a paso. |
| Características | Features | Variables de entrada del modelo. |
| Deriva de datos / del modelo | Data drift / model drift | Cambio en la distribución de los datos o degradación del desempeño en producción. |
| Destilación de modelos | Model distillation | Entrenar un modelo pequeño a partir de las respuestas de uno grande. |
| Equidad | Fairness | Ausencia de resultados sistemáticamente desfavorables para ciertos grupos. |
| Etiqueta | Label | Valor objetivo en aprendizaje supervisado. |
| Exactitud | Accuracy | (TP + TN) / total. |
| Explicabilidad | Explainability | Capacidad de explicar por qué el modelo produjo una salida. |
| Fragmentación | Chunking | División de documentos en fragmentos antes de generar embeddings. |
| Fuga de datos | Data leakage | Exposición indebida de datos (o filtración del test al entrenamiento). |
| Hiperparámetro | Hyperparameter | Configuración definida antes del entrenamiento. |
| Incrustación / vector semántico | Embedding | Representación numérica del significado de un contenido. |
| Inferencia | Inference | Uso del modelo entrenado para obtener predicciones. |
| Inferencia por lotes | Batch inference | Procesamiento asíncrono de grandes volúmenes. |
| Ingeniería de prompts | Prompt engineering | Diseño de instrucciones para guiar la salida del modelo. |
| Inyección de prompts | Prompt injection | Entrada maliciosa que intenta anular las instrucciones del sistema. |
| Matriz de confusión | Confusion matrix | Tabla de TP, FP, FN y TN. |
| Modelo fundacional | Foundation model (FM) | Modelo grande pre-entrenado adaptable a muchas tareas. |
| Modelo de lenguaje grande | Large language model (LLM) | FM especializado en texto. |
| Muestreo de núcleo | Top-P (nucleus sampling) | Muestreo sobre el conjunto mínimo de tokens con probabilidad acumulada ≥ P. |
| Precisión | Precision | TP / (TP + FP). |
| Pre-entrenamiento continuo | Continued pre-training | Entrenamiento adicional con datos de dominio sin etiquetar. |
| Rendimiento aprovisionado | Provisioned Throughput | Capacidad reservada de inferencia en Bedrock. |
| Responsabilidad compartida | Shared responsibility model | División de responsabilidades de seguridad entre AWS y el cliente. |
| Sensibilidad / exhaustividad | Recall | TP / (TP + FN). |
| Sesgo | Bias | Error sistemático (estadístico) o trato injusto (ético). |
| Sobreajuste | Overfitting | El modelo memoriza el entrenamiento y no generaliza. |
| Subajuste | Underfitting | El modelo es demasiado simple para capturar el patrón. |
| Temperatura | Temperature | Parámetro que controla la aleatoriedad de la generación. |
| Token | Token | Unidad mínima de texto procesada por el modelo. |
| Ventana de contexto | Context window | Máximo de tokens (entrada + salida) que el modelo puede manejar. |
| Generación aumentada por recuperación | Retrieval-Augmented Generation (RAG) | Añadir al prompt información recuperada de una fuente externa. |
| Humano en el ciclo | Human-in-the-loop | Intervención humana en decisiones o revisiones del sistema de IA. |
| Aprendizaje por refuerzo con retroalimentación humana | RLHF | Alineación de un modelo con preferencias humanas. |
