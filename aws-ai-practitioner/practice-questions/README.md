## Formato del examen real

| Aspecto | Valor |
|---|---|
| Preguntas | 65 (50 puntúan + 15 sin puntuación, no identificadas) |
| Duración | 90 minutos |
| Puntaje para aprobar | 700 / 1000 (escala) |
| Tipos | Opción múltiple, respuesta múltiple, **ordenación**, **emparejamiento** y **casos de estudio** |
| Penalización por error | No: responde siempre |

## Cómo practicar

1. Responde sin mirar la solución y anota tu nivel de confianza (alta / media / baja).
2. Despliega la solución (`▶ Ver respuesta`) y lee la justificación **de todas las opciones**, también las incorrectas.
3. Registra los fallos y las respuestas acertadas con baja confianza: son tu lista de repaso.
4. Objetivo antes del examen: **≥ 85 %** de aciertos de forma consistente.
