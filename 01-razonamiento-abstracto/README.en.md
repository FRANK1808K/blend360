# 01 · Abstract reasoning (30 minutes)

> A candidate who went through the Blend360 process in **Bogotá (May 2026)** reported **logic and abstract reasoning tests that were "quite demanding"**. The good news: abstract reasoning **can be trained**. There are only a few types of rules and they repeat. Once you learn to recognize them, you get much faster.

## 1. What does it measure?

The ability to **discover rules and patterns in new information** (figures, numbers, letters) **without prior knowledge**. Psychometrics calls this *fluid intelligence*. In data work, it is the equivalent of "seeing the pattern" in a problem you have never seen before.

**Typical format:** 20 to 40 questions in 30 minutes → **45 to 90 seconds per question**. Difficulty usually **increases** as you go, so **do not get stuck on the first ones**.

## 2. Question types

| Type | What it looks like | Example tests |
|---|---|---|
| **Figure series** | 4–5 figures in a sequence; choose the next one | "Abstract reasoning" tests (SHL, Aon/cut-e, Mettl) |
| **3×3 matrices** | A grid with one empty cell | **Raven** (Progressive Matrices) |
| **Dominoes** | Tiles with 0 to 6 dots; choose the missing tile | **D-48 / D-70** (widely used in Latin America) |
| **Analogies** | A is to B as C is to ? | — |
| **Odd one out** | Which one does not belong to the group? | — |
| **Number and letter series** | 2, 6, 18, 54, ? | Numerical/logical aptitude tests |
| **Sets A / B** | Set A follows one rule and set B another; where does the figure belong? | SHL "inductive" tests |
| **Spatial** | Rotate, reflect, fold cubes | — |

## 3. The rules that repeat: the **"FORMA-CPR"** checklist

The mnemonic comes from Spanish, so you learn one checklist for both languages. When you see a sequence, check **in this order** what changes from one figure to the next:

| Letter | What to check | Questions to ask yourself |
|---|---|---|
| **F**orm (*Forma*) | Does the type of figure change? | Circle → square → triangle? Do the sides increase (3, 4, 5…)? |
| **O**rientation | **Rotation** or **reflection** | Does it rotate 45°, 90° or 180°? Clockwise or counterclockwise? Is it mirrored? |
| **R**elleno = fill / color | White, black, striped | Does it alternate? Does the color rotate between elements? |
| **M**ovement / position | Where each element is | Does it move 1 cell? Does it go around the corners clockwise? Does it bounce at the edge? |
| **A**mount | Number of elements, sides, dots, lines | +1, −1, ×2? Sum of the previous ones? |
| **C**ombination | Overlapping figures | Is the 3rd figure = 1st + 2nd? Are the common lines removed (XOR)? |
| **P**roportion / size | Big, medium, small | Does it grow and shrink? |
| **R**epetition / cycle | A pattern that starts again | Does it repeat every 2, 3 or 4 steps? |

> 💡 **Key:** there are almost always **2 or 3 rules at the same time** on **different** elements. For example, the arrow rotates 90° **and** the dot alternates black/white. Analyze **each element separately**.

### Rotations you must recognize instantly

```text
Clockwise 90°:          ↑ → ↓ ← ↑
Clockwise 45°:          ↑ ↗ → ↘ ↓ ↙ ← ↖ ↑
Counterclockwise 90°:   ↑ ← ↓ → ↑
180°:                   ↑ ↓ ↑ ↓
Vertical-axis reflection (left-right mirror): ↗ ↔ ↖ ,  ◐ ↔ ◑
```

### 3×3 matrices: the 6 most common rules

1. **Progression** along the row or the column (it grows, rotates, moves).
2. **Each row contains each element once** (like a sudoku: ○ △ □ in different orders).
3. **Addition/subtraction:** column 3 = column 1 + column 2 (or the overlay).
4. **XOR:** column 3 shows only what does **not** match between columns 1 and 2.
5. **Constant attribute** per row (same shape) and **variable** per column (different fill).
6. **Counting:** the number of elements follows a rule (1, 2, 3 or a sum).

> Check **rows** first. If you cannot find the rule, check **columns**, then **diagonals**.

### Dominoes (D-48)

- Each half has **0 to 6** dots and the sequence is **circular**: after 6 comes 0 (6 + 1 = 0; 0 − 1 = 6).
- Analyze the **top half** and the **bottom half separately**.
- Typical patterns: +1, −1, +2, alternation, the bottom half of one tile equals the top half of the next, a constant sum.

## 4. Strategy for the 30 minutes

1. **Look at the answer options first:** they tell you **what changes**. If all the options are the same arrow at different angles, the rule is about **rotation**.
2. **Eliminate options** that break the most obvious rule; you often end up with 2.
3. **The 60-second rule:** if you see nothing in 1 minute, **flag it, guess and move on**. Come back at the end.
4. **Never leave a blank** if wrong answers are not penalized.
5. **Check your rule** against **all** the figures, not only the first two.
6. **Talk to yourself** in simple words: "rotates 90 to the right, the dot alternates, one side is added".
7. Keep the pace: at **15 minutes** you should be halfway.

## 5. Training plan

| Week | Daily (15–20 min) |
|---|---|
| 1 | 10 number/letter series + 10 figure items ([exercises](ejercicios.en.md)) **without a timer**, to learn the rules |
| 2 | Simulator in practice mode, 20 questions with a timer: goal of 75 s per question |
| 3+ | Full **30-minute** mock exam 3 times a week: goal of 45–60 s per question |
